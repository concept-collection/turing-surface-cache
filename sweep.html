turing-surface-cache — parameter sweep

One model parameter runs over a list of values while everything else stays fixed; the knob steps the display through the range. The list starts as the values the single-solution page offers, and any numbers may be typed in its place. Values already in the shared cloud cache are loaded up front, so dragging the knob is instant; values nobody has computed show as gaps until Compute missing values runs them here, or the command below runs them on another machine. One color scale covers the whole sweep, so differences between values are real. Back to the single-solution page.

Solutions computed here can be contributed back to the shared cache, so the next visitor gets the whole sweep instantly. Contributing requires an upload API key.
